# Masud Portfolio v1.0

Personal portfolio website for Md. Moshiur Rahman (Masud).

## Run locally
Because the website loads JSON using `fetch()`, open it through a local web server (for example VS Code Live Server), or deploy it to GitHub Pages.

## Add images
Put your images here:
- assets/images/profile.jpg
- assets/images/project-1.jpg
- assets/images/project-2.jpg
- assets/images/project-3.jpg

You can replace these files with your own images using the same filenames.

## Editable content
Edit `data/portfolio.json`.

CMS integration can be added in the next phase.
