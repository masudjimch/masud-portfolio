# Portfolio Browser Editor

## What this does
Open `index.html` in any browser. You can:
- Import your existing `portfolio.json`
- Edit your profile, about, skills, experience, projects and contact information using forms
- Add or remove items with buttons
- Download a new `portfolio.json`

## How to update the website
1. Open `editor/index.html` in your browser.
2. Click **Import existing portfolio.json** and choose `data/portfolio.json`.
3. Edit the information.
4. Click **Download portfolio.json**.
5. On GitHub, open `data/portfolio.json`.
6. Replace its contents with the downloaded file's contents, or upload/replace the file using GitHub's interface.
7. Commit changes.
8. GitHub Pages will update the website.

## Important
This first version covers the main content fields already present in the current portfolio data. It does not yet include services or publications. Those can be added in the next version without rebuilding the editor.
